01 / INSTALL

在 Mac 上安装

需要 Microsoft 365 PowerPoint。安装前，请先完全退出 PowerPoint。

Terminal · zsh 
mkdir -p "$HOME/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef" && \
curl -fsSL https://slide2pdf.duanyll.com/manifest.xml \
  -o "$HOME/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/Slide2Pdf.xml"

  1. 1

    复制并运行

    打开“终端”，粘贴上面的命令并按回车。

  2. 2

    重新打开 PowerPoint

    打开任意演示文稿，进入“开始”选项卡。

  3. 3

    打开 Slide2Pdf

    点击“加载项”，选择 Slide2Pdf，然后开始导出。

不想使用终端？可以下载 XML 清单， 再将它放入 ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/。

02 / LOCAL

演示文稿和 PDF 不会上传。

转换在 PowerPoint 任务窗格内完成；服务器只负责加载插件页面。

03 / UPDATE

大多数更新会自动生效。

重新打开任务窗格即可加载大多数更新。清单权限或 PowerPoint 按钮发生变化时， 才需要重新运行安装命令。
