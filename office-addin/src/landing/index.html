01 / INSTALL

一分钟装好。

适用于装有 Microsoft 365 PowerPoint 的 Mac。开始前，请先完全退出 PowerPoint。

Terminal · zsh 
mkdir -p "$HOME/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef" && \
curl -fsSL https://slide2pdf.duanyll.com/manifest.xml \
  -o "$HOME/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/Slide2Pdf.xml"

  1. 1

    复制并运行

    打开“终端”，粘贴上面的命令并按回车。

  2. 2

    重新打开 PowerPoint

    打开任意演示文稿，进入“开始”选项卡。

  3. 3

    找到 Slide2Pdf

    选择“加载项 → Slide2Pdf”，然后开始导出。

不想使用终端？ 下载 XML 清单 后手工放入 PowerPoint 的 wef 目录。

02 / LOCAL

你的幻灯片不离开 PowerPoint。

服务器只提供插件的静态 HTML 和 JavaScript。PowerPoint 在任务窗格内生成整份 PDF，Slide2Pdf 在本机内存中抽取当前页并裁切，然后触发系统下载。

03 / UPDATE

以后更新，不用重装。

功能更新会直接部署到网页端。通常关闭再打开任务窗格就能使用新版；只有清单权限或 PowerPoint 按钮发生变化时，才需要重新运行安装命令。
